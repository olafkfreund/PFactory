# Plan: Cap PFactory's DB connection pools

Approved decisions: a dependency-free helper `server/db_pool.py`
`pool_kwargs(url, prefix, size, overflow)` returns `{}` for SQLite URLs, else
`pool_size` from `<prefix>_POOL_SIZE`, `max_overflow` from
`<prefix>_MAX_OVERFLOW`, `pool_timeout` from `DB_POOL_TIMEOUT` (default 10).
Defaults: main `DB` 5+3, JobStateStore `JOBSTORE_DB` 2+2, PlanSessionStore
`PLAN_SESSION_DB` 2+2. Relay unchanged. Per pod 38 → 19.

## Steps

1. Add `apps/web-server/server/db_pool.py` with `pool_kwargs`; use it in
   `server/database/engine.py` (the `create_async_engine` call,
   `**pool_kwargs(DATABASE_URL, "DB", 5, 3)`), `server/jobstore/store.py`
   `_make_engine_coro` (`"JOBSTORE_DB", 2, 2`) and
   `server/jobstore/plan_session_store.py` `_make_engine_coro`
   (`"PLAN_SESSION_DB", 2, 2`), replacing the hard-coded `pool_size=5,
   max_overflow=5`. → verify by `cd apps/web-server && ruff check server && python -c "import server.db_pool"`
   Traps: do not import `server.database` from `db_pool.py` (it builds the
   engine); keep `pool_pre_ping=True`.
2. Add `apps/web-server/tests/test_db_pool_caps_961.py`: `pool_kwargs`
   defaults, env override, SQLite → `{}`, bad int raises; and
   `JobStateStore._make_engine_coro` / `PlanSessionStore._make_engine_coro`
   on a `postgresql+asyncpg://` URL give `engine.pool.size()` 2 and
   `engine.pool._max_overflow` 2 (no connection is opened). → verify by
   `pytest tests/test_db_pool_caps_961.py`
   Traps: Codex's sandbox hangs on aiosqlite; the lead runs the DB suites.

## Tests

`cd apps/web-server && pytest -q` (SQLite) and the same with `DATABASE_URL`
pointing at a local Postgres; ruff; `scripts/ratchet_lint.py` if present.

## Rollback

Revert the PR, or raise the caps through the env vars without a release.
