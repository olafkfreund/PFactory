# Spec: PFactory UI test fixes

## Design

- **B2a.** `ensure_tracked_project` (`routes/projects.py:241-291`) resolves
  the org when the caller passes none: the creator's org if known, else the
  deployment default org. This is the same default `create_project` uses
  (`:606-613`). All call sites in `plan_pipeline.py` (`:329,393,462,512`)
  pass the principal's org when available.
- **B2b.** On registry load, a project with no `org_id` is stamped with the
  default org and saved once, idempotently. With multiple orgs configured,
  it is not guessed: it is logged as unassigned and stays hidden.
- **B2c.** `charts/pfactory/templates/deployment.yaml:368-369` gets
  `persistence.data`: an existing claim or a PVC template, defaulting to
  `emptyDir` with a values comment. That matches how gitops already mounts
  `data` at `~/.pfactory`.
- **B4.** The version comes from `/api/health`, cached, with "unknown" on
  failure.
- **B9.** The nav label for view `pfactory` becomes "Plans"
  (`navigation.json:7`, all locales). The page title becomes "Plans" with
  the subtitle "Plan sessions in this project"
  (`PFactoryPortal.tsx:34-36`). The empty state says "No plans yet. Ingest
  a plan or an issue; approved plans hand over to AIFactory."
  (`PFactoryTaskList.tsx:136-137`). Update `PFactoryPortal.test.tsx:79`.
- **B10.** `AddProjectModal.tsx`: default clone with no scan on open, as in
  AIFactory and TFactory.

## Alternatives rejected

Lowering the visibility filter to show org-less projects: that is an
existence or visibility leak across orgs.

## Risks

- B2b must not stamp in a multi-org deployment where the owner org is
  ambiguous.

## Verification

- Unit tests:
  - `ensure_tracked_project` stamps an org;
  - load backfills a single-org registry;
  - the multi-org case is not guessed;
  - the visibility filter shows the stamped project to org members and not
    to other orgs.
- vitest for B4, B9 and B10.
- `helm template` with and without persistence.
- CI.
- After release, a browser check: PFactory lists the project and the
  menus are enabled.
